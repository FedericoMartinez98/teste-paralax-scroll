# ✨ AURA // Premium Parallax Cinematic Experience

> Uma experiência cinematográfica de **Parallax Scroll** inspirada nos padrões visuais e de engenharia de **Apple, Linear, Studio Freight e vencedores do Awwwards**.

---

## 🌟 Destaques do Projeto

* 🚀 **60 FPS Constante & Smooth Scrolling**: Momentum inercial ultra-fluido com **Lenis**.
* 🎭 **Coreografia de Scroll com GSAP & ScrollTrigger**: Timelines sincronizadas milimetricamente por `scrub` e seções `pin`.
* 💎 **Artefato 3D & Campo de Partículas WebGL (Three.js)**: Escultura geométrica refrativa com iluminação de três pontos e milhares de partículas dinâmicas no espaço.
* 🌌 **Parallax Multi-Camadas**: 3 planos de profundidade independentes que simulam a ótica de lentes anamórficas de cinema.
* 📖 **Storytelling Cinemático**: Viewport fixada com revelação progressiva frase a frase (*fade-in*, elevação e *progressive blur*).
* 🎛️ **Sticky Modular Transformation**: Metamorfose entre 3 estados de conceito de design ao longo do scroll virtual.
* 🔍 **Efeitos de Luz Especular (Spotlight) & 3D Tilt**: Microinterações nos cartões que respondem às coordenadas do mouse.
* 🎵 **Sintetizador Sonoro Integrado**: Paisagem sonora cinematográfica com osciladores e filtros gerados em tempo real via **Web Audio API**.
* 🎯 **Cursor Magnético Personalizado**: Ponto luminoso com halo fluido que se atrai magneticamente por botões e elementos interativos.

## 🛠️ Tecnologias Utilizadas

* **Vite** — Ferramenta de build rápida e moderna
* **Vanilla JavaScript & Modern ES Modules**
* **GSAP 3** (`gsap`, `ScrollTrigger`)
* **Lenis** (`lenis`) — Smooth scroll de alta fidelidade
* **Three.js** (`three`) — Renderização 3D WebGL
* **Vanilla CSS 3** — Design system com aceleração por GPU

## 🚀 Como Rodar Localmente

### Pré-requisitos
* [Node.js](https://nodejs.org/) (v18 ou superior)
* `npm` ou `yarn` / `pnpm`

### Instalação e Execução

```bash
# 1. Clone o repositório
git clone <URL_DO_SEU_REPOSITORIO>

# 2. Acesse a pasta do projeto
cd "teste paralax scroll"

# 3. Instale as dependências
npm install

# 4. Inicie o servidor local
npm run dev
```

Abra `http://localhost:5173` em seu navegador para vivenciar a experiência.

---

## 📦 Build para Produção

```bash
npm run build
```

Os arquivos estáticos otimizados serão gerados na pasta `dist/`.
